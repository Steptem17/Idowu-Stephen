## ⚡ Quick Start & Development

1. **Clone or navigate to the repository**:
   ```bash
   cd my-portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Production Build & Verification**:
   ```bash
   npm run build
   ```
